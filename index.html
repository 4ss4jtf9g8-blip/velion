🤖 Как создать Telegram-бота для уведомлений

1
Напишите @BotFather в Telegram и отправьте команду /newbot
2
Придумайте имя и username для бота. BotFather выдаст вам токен — скопируйте его
3
Узнайте свой Chat ID: напишите @userinfobot в Telegram, он пришлёт ваш ID
4
Вставьте токен и Chat ID в поля выше — и готово! Бот будет присылать вам новые заказы
⚠️ Примечание: мониторинг Kwork работает через публичный API. Telegram-чаты парсятся по ключевым словам из публичных групп.
